# GTA V Inspired 3D Animation 🚗

## 📌 Project Overview

This project is a GTA V-inspired 3D animation created to explore vehicle movements, object animations, and 3D environment design.

The scene features vehicles moving along a road within a city environment, surrounded by buildings, street lights, and crowd elements.

The main objective of this project was to gain practical experience in 3D animation techniques and understand how different objects can be animated and organized within a 3D scene.

## 🎯 Learning Outcomes

During this project, I explored and practiced the following concepts:

- **Object Arrays:** Creating and arranging multiple objects efficiently.
- **Object Parenting:** Establishing parent-child relationships between objects to control and organize them together.
- **Vehicle Wheel Rotation:** Animating vehicle wheels to simulate realistic movement.
- **Object Movement Animation:** Creating movement animations for different objects.
- **Keyframe Animation:** Inserting and managing keyframes to control object movements and rotations over time.
